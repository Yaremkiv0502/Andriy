# JARVIS Core & Automated Trading Engine

An intelligent autonomous execution architecture and AI analytical assistant.

## System Architecture
- **Event Bus Engine**: Low-latency event-driven pipeline and signal routing.
- **AI Integration**: Amazon Bedrock API (Anthropic Claude 3.5 Sonnet) for code generation, strategy optimization, and risk evaluation.
- **Infrastructure**: Microservices deployable via AWS EC2 container instances.
